# Booking Service

Starlight Stays & Resorts — Booking Microservice

## STEP 1
Initial project structure only.

Planned responsibilities:
- Create and manage bookings
- Validate booking dates and guest count
- Prevent overlapping confirmed bookings
- Communicate with Room Service
- JWT-protected APIs
- Eureka service discovery
- API Gateway integration
- Testing and deployment readiness

## Planned package structure

- controller — REST APIs
- dto — request/response objects
- entity — database entities and enums
- repository — Spring Data repositories
- service — business logic
- exception — centralized error handling
- client — inter-service clients
- config — application/security configuration

Configuration and pom.xml will be added in STEP 2.
